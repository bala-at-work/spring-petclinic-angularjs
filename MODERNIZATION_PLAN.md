> Generated by `@skills:java-modernization-assess` (kit v0.4) on 2026-11-14. Evidence-based: every
> version below cites the file it came from or the command that showed it.
> Owner preferences: `frontend=angular java=21 db=postgres`.

## 1. Summary
- **Archetype:** `A-boot-spa` — `pom.xml:7-11` inherits `spring-boot-starter-parent` 2.1.3.RELEASE, the server
  exposes `@RestController`s (`web/*Resource.java`), and the client is an AngularJS SPA built with Bower
  (`spring-petclinic-client/bower.json`) + Gulp (`gulpfile.js`) + an old `package.json`. All three archetype-A signals present.
- **Current → target:** Java 8 → **21** (owner choice; LTS, Temurin EOL 2029-12-31) · Spring Boot 2.1.3 →
  **4.1.x** (current GA line, 4.1.2 at assessment, via 2.7 and 3.5) · AngularJS 1.6.10 → **Angular 22.x**
  (current major, active support to 2027-06-30) · Bower/Gulp 3/Node 4 → npm + Vite + Node LTS ·
  HSQLDB/MySQL SQL scripts → **Postgres + Flyway** (owner choice).
- **Size:** ~1,729 backend Java LOC (main) + ~397 test LOC; ~1,005 frontend LOC (JS/HTML/LESS/CSS);
  11 REST endpoints; 7 UI screens (9 routes); 3 executing tests.
- **Overall risk:** **Medium** — the app is small and the baseline is green on JDK 8, but only 3 tests run,
  three framework majors must be crossed (Boot 2→3→4, `javax`→`jakarta`), and the whole UI is rewritten.
- **Task count:** 23 (6 S, 17 M, 0 L). Baseline build passes on JDK 8: **yes**.

## 3. Security & dependency findings
- **EOL:** Java 8 (as language level; JDK still has vendor support) · Spring Boot 2.1.x (EOL; even 2.7 OSS support ended
  2023-06-30 per spring.io) · Spring Framework 5.1.x · AngularJS 1.x (EOL 2021-12-31, endoflife.date) ·
  Node 4 (EOL 2018-04-30) · Gulp 3 · Bower (deprecated) · Maven 3.3.3 · MySQL 5.7 image · `openjdk` Docker image (deprecated).
- **Notable CVEs** (OSV API lookup for the resolved versions, 2026-11-14; to be triaged in T21):
  - `jackson-databind` 2.9.8 — 60 advisories (12 critical, 41 high), polymorphic-deserialization family.
  - `tomcat-embed-core` 9.0.16 — 54 advisories (9 critical, 27 high).
  - `spring-beans`/`spring-webmvc` 5.1.5 — incl. CVE-2022-22965 (Spring4Shell; critical); `spring-webmvc` 13 advisories (2 critical, 4 high).
  - `spring-boot-actuator-autoconfigure` 2.1.3 — CVE-2023-20873 (critical); actuator exposes all endpoints (`application.properties:29`).
  - `thymeleaf` 3.0.11 — 3 critical; `snakeyaml` 1.23 — 8 (3 high); `hsqldb` 2.4.1 — CVE-2022-41853 (critical).
  - Frontend: `angular` 1.6.10 — 12 advisories (XSS/ReDoS, no fix in 1.x); `bootstrap` 3.3.7 — 7 (XSS); `jquery` 3.2.1 — 3.
- **Dependency report:** `JAVA_HOME=$JAVA_HOME_8 ./mvnw -B versions:display-dependency-updates versions:display-plugin-updates`
  ran successfully. Direct highlights: Spring Boot parent 2.1.3 → 4.1.x; `frontend-maven-plugin` 1.3 → 2.0.2;
  `docker-maven-plugin` 0.4.13/1.2.0 → 1.2.2 (still unmaintained — replace in T22). The Maven wrapper (3.3.3) is not
  covered by the report. Most transitive CVEs are cleared by the Boot hops (T4, T6, T7).

## 4. Risks & unknowns
- **Thin safety net:** 3 tests today. T2/T3 must land before any upgrade; every later acceptance criterion leans on them.
- **Repo-wide hops that can't be sliced:** JDK 17/21 (T5, T8) and Boot 2.7/3.5/4.1 (T4, T6, T7). Mitigation: OpenRewrite
  recipes, recipe output in its own commit, T2/T3 green before and after. T6 (`javax`→`jakarta`, Hibernate 6) is the riskiest.
- **Legacy frontend toolchain:** Gulp 3 does not run on modern Node; T9/T10 should land back-to-back or keep Node pinned in between.
- **Angular coexistence:** two frameworks served from one webjar during T11–T17; routing hand-off between hash-prefixed
  ui-router URLs (`#!/owners`) and Angular routes must be decided in T11.
- **Postgres vs. existing vendors:** schema exists twice (HSQLDB, MySQL); Flyway baseline must reproduce the HSQLDB
  seed data exactly, and sequences must be reset after seeding. Owner decision: MySQL goes in T19, HSQLDB in T20
  (Postgres only; zero-setup `spring-boot:run` is given up).
- **Wire contract:** `GET /owners/*/pets/{petId}` (wildcard) and the date formats in pets/visits must survive Boot 3 path
  matching and Jackson changes — covered by T2.
- **Unknowns:** behaviour on JDK 17+ was not tried (baseline only); coverage not measured; Docker image never built in
  the assessment (compose references an external image and a missing `./conf.d`).
